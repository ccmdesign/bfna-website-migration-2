## 1. Introduction

This document provides recommendations for improving BFNA's website structure, navigation, and content presentation.

It builds on prior accessibility and audience strategy work and includes illustrative copy direction. Final copy will follow alignment on structure and navigation.

See our [Audience-Centric Web Strategy report](https://docs.google.com/document/d/130ATdVXD3qsSAB4r1Oh6UwIu5dNfocw0-QIk3LDfC3U/edit?usp=sharing) for more information on our website redesign priorities and guiding principles.

## 2. Key Challenges

BFNA's website reflects the depth of its work but lacks a clear system for organizing and prioritizing content. The following challenges limit usability and engagement.

### Fragmented Navigation System
- Multiple overlapping navigation systems
- Redundant pathways and lack of hierarchy

### Unclear Content Model
- No clear distinction between focus areas, programs, and content
- Platforms appear disconnected

### Content Overload
- Too much content surfaced equally
- Outdated content shown as current

### Weak User Pathways
- No clear next steps
- Generic CTAs

## 3. Content Strategy Framework

BFNA's site should be structured around a clear content system that defines what exists, how it is organized, and how users navigate between elements.

### Content Visibility Framework
- **Tier 1:** Core content (active, recent)
- **Tier 2:** Supporting content (searchable)
- **Tier 3:** Archive (3+ years old, exceptions apply)
  - *Note: Archiving does not mean deleting the content off of the website. We still want this content to be accessible for [AI search engine optimization](https://digitalmarketinginstitute.com/blog/optimize-content-for-ai-search).*

### Content Model
The site should distinguish between key content types to improve clarity and scalability.
- **Institutional Content** (mission, team, about)
- **Focus Areas** (Democracy, Politics & Society, Future Leadership, Digital World)
- **Programs & Platforms** (Fellowship, Barometer, Periscope, etc.)
- **Insights** (articles, reports, videos)

### Discoverability
Content should be structured so users and search engines can easily find and understand it.
- Introduce tagging (focus area, program, format)
- Standardize page structures (including clear intro paragraphs explaining the core focus)
- Strengthen focus area landing pages as hubs

> **A Note on AI Search + Discoverability Considerations** *(callout box in original)*
>
> As search behavior shifts toward AI-generated summaries and answer-based interfaces, BFNA's website should be structured to ensure its content is easily understood, surfaced, and cited. That includes:
> - Implementing schema across content types
>   - **Schema = structured data** (e.g., BFNA might have organization, article, report/publication, video, and event schema on its website).
> - Using clear, descriptive titles and summaries
> - Strengthening relationships between focus areas, programs, and content
> - Introducing tagging to support content organization
> - Ensuring consistent page structures

## 4. Site Flow + User Journeys

The site should guide users through a small number of clear pathways based on common audience needs and behaviors.

### Primary Users
- Policymakers and institutional stakeholders
- Researchers and subject-matter experts
- Program participants
- General audiences

### Key Journeys
- **First-time visitor:** Homepage → Focus Area → Content → Subscribe
- **Topic explorer:** Focus Area → Content → Program
- **Program user:** Program → Action
- **Content visitor:** Content → Focus Area → Program

## 5. Cross-Site UX Recommendations

These recommendations apply across all pages to improve usability, clarity, and engagement:

- **Clarify content model:** Clearly distinguish between focus areas, programs, and content.
- **Prioritize pathways:** Guide users toward key actions instead of presenting too many options.
- **Reduce cognitive load:** Simplify layouts and limit competing elements.
- **Use strong CTAs:** Replace generic language with specific actions.
- **Signal external links:** Clearly indicate when users leave the site.
- **Standardize templates:** Ensure consistent page structures.

## 8. Accessibility Considerations

Accessibility should be integrated across all aspects of the redesign to ensure usability for all audiences. This includes:
- Clear heading hierarchy
- Accessible navigation
- Color contrast compliance
- Keyboard navigation
- Alt text and media labeling

*Reference: See our [Accessibility Audit](https://docs.google.com/document/d/1ASUJAtfhDdnxk1R12z2vSKAKWo28HOQdXbTDcMsPBRw/edit?usp=sharing) for more guidance.*

## 9. Future Brand Alignment

BFNA's website redesign should be aligned with the upcoming Bertelsmann Stiftung rebrand to ensure consistency across the broader institutional ecosystem. While the timeline for the rebrand extends beyond the immediate website work with GGS and CCM Design, early coordination will help avoid rework and support a more cohesive visual and messaging system.
- Align with Stiftung rebrand
- Develop visual and voice system

## 10. Implementation Considerations

Successful implementation of these recommendations will require coordination between BFNA, CCM Design, and internal stakeholders. Although not within the current project scope, the GGS team may be available for future consultation (pending discussion of a contract extension).

In addition to design and development, establishing clear content governance and system-level decisions will be critical to maintaining clarity and consistency over time. Next steps towards this goal — yet beyond this project with GGS — include the development of tagging systems and CMS templates.
