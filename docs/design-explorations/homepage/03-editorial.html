Direction 03

JOURNAL OF RECORD (EDITORIAL)

A think tank is a publisher. The homepage is a front page: masthead, dateline, lead story, columns, kickers, captions.

Typefaces

Fraunces variable — opsz 14/144, wght 400/700, SOFT 0, WONK 0/1, roman + italic

Inter — 400/500/600/700, 17px body

Scale: 104 / 64 / 44 / 28 / 26 / 24 / 22 / 17 / 13

Palette

PAPER #F6F2EA
INK #141210
ACCENT #B5333F
NAVY #003C5C
DEMOCRACY #116F7E
TRANSATL. #8A5709
FUT. LEAD. #C23C4A

Three principles

  1. A front page, not a landing page. Bands are sections of a paper; every one opens on a double rule and a folio.
  2. Structure is carried by rules, kickers, datelines and captions — never by colour. One accent (#B5333F); programme hues only as kicker text; navy only in the footer.
  3. Scale is the only loud thing: 104px Fraunces on paper, one drop cap, and everything else set quietly at 17px.

Programme hues darkened from the token values (#A3680F → #8A5709, #CF4457 → #C23C4A) to clear 4.5:1 on paper. Same hue family.
